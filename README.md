# FitCircle

Social fitness accountability: join a circle, stake money on showing up, prove every session.

## Prototype

`prototype/index.html` is a clickable MVP of the full 8-step journey for all three challenge formats:

- **Peer Groups**: weekly target, shared Jackpot, forfeits go to completers
- **Instructor Challenges**: verified coaches, paid 1–12 week programmes, 70–80% to the instructor
- **Custom 75-Day**: build your own 75 Hard / 75 Soft with daily tasks

Open the file in a browser. Use the left-hand rail to switch formats or jump to any step.
